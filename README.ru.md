# Aux Command

**Aux Command** — это бесплатная, open-source, нативная Linux рабочая станция удалённых операций от Auxillo: защищённая консоль для операторов, которым нужны SSH-терминалы, SFTP, туннели, средства удалённого рабочего стола, Mosh, Telnet, последовательные консоли, локальные оболочки, профили и готовые к эксплуатации инструменты в одном приложении.

Разработана для технических операторов, команд инфраструктуры и инженеров безопасности, которым нужно быстро работать в локальных и удалённых системах, не разбрасывая задачи между множеством несогласованных инструментов.

## Основные возможности

- **Терминал** — Рабочее пространство с вкладками и PTY-терминалом на xterm.js, локальные сессии, настраиваемые темы, разделённые макеты, палитра команд, запись макросов и групповая отправка ввода.
- **SSH** — Нативные сессии OpenSSH, поддержка SSH-агента, импорт `~/.ssh/config`, файлы идентификации, ProxyJump, сжатие, keepalive, проброс X11 и SCP fallback.
- **SFTP** — Графический SFTP-браузер с подтверждением отпечатка ключа хоста, загрузка/скачивание, встроенное редактирование текста и управление папками.
- **Туннели** — Локальные, удалённые и динамические SOCKS-туннели с проверкой готовности на основе фактического состояния OpenSSH.
- **Протокольные запуски** — Mosh, RDP через FreeRDP, VNC через TigerVNC, встроенный Telnet и последовательный мост на Python.
- **FTP / FTPS** — Графический FTP/FTPS-браузер с предупреждением о незащищённом соединении для обычного FTP.
- **Релизы и диагностика** — Автоматическое обновление через GitHub Releases, панель управления обновлениями, сборка для AppImage/.deb/.rpm, SBOM и верификация контрольных сумм.

## Быстрая установка

### AppImage
```bash
chmod +x Aux-Command-0.1.0-x86_64.AppImage
./Aux-Command-0.1.0-x86_64.AppImage
```

### Debian / Ubuntu
```bash
sudo apt install ./Aux-Command-0.1.0-amd64.deb
aux-command
```

### Fedora / RHEL
```bash
sudo dnf install ./Aux-Command-0.1.0-x86_64.rpm
aux-command
```

## Безопасность

Aux Command спроектирован для операций, чувствительных к безопасности. Ключевые меры: изолированный рендеринг Electron, запрет Node.js в рендерере, проверка IPC-отправителя, запуск процессов через массивы аргументов (без shell-интерполяции), защита дочерних процессов сигналом смерти родителя, отдельное хранение SFTP-ключей и шифрованное хранение секретов.
