# Aux Command

**Aux Command** — бесплатная рабочая станция Auxillo для удалённого администрирования с открытым исходным кодом, созданная специально для Linux: одно защищённое настольное приложение для SSH-терминалов, SFTP, FTP/FTPS, SSH-туннелей, удалённых рабочих столов RDP и VNC, Mosh, Telnet, последовательных консолей и локальных оболочек.

Оно предназначено для технических специалистов, инфраструктурных команд и инженеров по безопасности, которые работают с множеством локальных и удалённых систем и хотят единое рабочее пространство вместо набора разрозненных инструментов.

> Текущая версия: **0.5.0** для Linux x86_64. Релизы подписаны GPG.

## Основные возможности

- **Рабочее пространство терминала** – Вкладки можно перетаскивать в любом порядке и переименовывать (двойной щелчок или F2), для каждого подключения задаётся свой цвет (например, красный для продакшена); одиночная или плиточная раскладка, открепляемые окна терминала, масштабирование терминала (Ctrl+= / Ctrl+- / Ctrl+0), 14 тем оформления, поиск, макросы и групповой ввод.
- **Копирование и вставка как в терминале Linux** – Выделение копирует текст, средняя кнопка мыши вставляет, правая открывает меню (или копирует и вставляет в стиле PuTTY); также работают Ctrl+Shift+C / Ctrl+Shift+V и Ctrl+Insert / Shift+Insert. Ctrl+щелчок открывает ссылки.
- **SSH** – Нативные сессии OpenSSH, SSH-агент, импорт `~/.ssh/config`, файлы идентификации, ProxyJump, сжатие, keepalive и проброс X11.
- **SFTP и FTP/FTPS** – Двухпанельный файловый менеджер с предварительной проверкой передач, передачей папок, сравнением и синхронизацией, встроенным редактированием текста и очередью передач. SFTP учитывает ключи, которым OpenSSH уже доверяет в `known_hosts`.
- **SSH-туннели** – Локальный, удалённый и динамический (SOCKS) проброс портов; туннель отмечается как готовый, только когда он действительно работает.
- **Удалённые рабочие столы** – Встроенные вкладки RDP и VNC, внешние клиенты FreeRDP/TigerVNC, а также RDP/VNC через SSH-шлюз.
- **Рабочие пространства** – Именованные сохранённые рабочие пространства, восстановление сессий, группы подключений, избранное, резервные копии рабочих пространств и локальные точки восстановления.
- **Помощник терминала** – Определение ОС для каждой сессии, встроенные подсказки команд (Ctrl+Space), исправления «возможно, вы имели в виду» и защита перед выполнением опасных команд; каждую функцию можно отключить. Ничто из введённого в запросе пароля не отображается, не предлагается и не сохраняется.
- **Продуктивность** – Поиск по истории всех сессий, выполнение одной команды в нескольких сессиях со сбором вывода, воспроизведение сессий, статистика хостов в реальном времени и сетевые инструменты.
- **Опциональная помощь ИИ** – По умолчанию отключена; использует ваш собственный OpenAI-совместимый эндпоинт (например, llama.cpp или Ollama). Ответы только вставляются и никогда не выполняются.
- **Интерфейс на русском языке** – Интерфейс доступен на 9 языках, а язык можно переключить в строке состояния.

## Быстрая установка

```bash
# AppImage (портативная версия)
chmod +x Aux-Command-0.5.0-x86_64.AppImage
./Aux-Command-0.5.0-x86_64.AppImage

# Debian / Ubuntu
sudo apt install ./Aux-Command-0.5.0-amd64.deb
aux-command

# Fedora / RHEL / Rocky / AlmaLinux
sudo dnf install ./Aux-Command-0.5.0-x86_64.rpm
aux-command

# openSUSE
sudo zypper install ./Aux-Command-0.5.0-x86_64.rpm
aux-command
```

Mosh, RDP (FreeRDP) и VNC (TigerVNC) используют клиенты из самого дистрибутива; их устанавливает `./scripts/install-runtime-tools.sh`. Подробности — в [INSTALL.md](INSTALL.md).

## Безопасность

Aux Command отдаёт предпочтение явным границам доверия, а не незаметному удобству. Рендерер Electron работает в песочнице с `contextIsolation`, разрешения Chromium по умолчанию запрещены, внешняя навигация и всплывающие окна блокируются. Процессы запускаются напрямую с массивами аргументов и никогда не проходят через оболочку. Ключи хостов SSH и сертификаты серверов RDP подтверждаются при первом использовании, а изменившиеся помечаются; RDP привязывается к подтверждённому сертификату. Из вставляемого текста удаляются управляющие символы, а многострочная или групповая вставка сначала требует подтверждения. Пароли сохраняются только при наличии зашифрованного хранилища рабочего стола, а экспортируемые данные никогда не содержат секретов.

Сообщайте об уязвимостях конфиденциально, как описано в [SECURITY.md](SECURITY.md).
