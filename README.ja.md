# Aux Command

**Aux Command** は、Auxillo が提供する無料・オープンソースの Linux ネイティブなリモートオペレーション用ワークステーションです。SSH ターミナル、SFTP、FTP/FTPS、SSH トンネル、RDP・VNC リモートデスクトップ、Mosh、Telnet、シリアルコンソール、ローカルシェルを、一つの安全なデスクトップアプリで扱えます。

多数のローカル・リモートシステムをまたいで作業し、ばらばらのツールを使い分けるのではなく一貫したワークスペースを求める技術オペレーター、インフラチーム、セキュリティエンジニアのために作られています。

> 現在のバージョン：Linux x86_64 向け **0.4.0**。リリースには GPG 署名が付いています。

## 主な機能

- **ターミナルワークスペース**：ドラッグで自由に並べ替えたり名前を変更（ダブルクリックまたは F2）したりできるタブ、接続ごとの色分け（例：本番環境は赤）、単一表示またはタイル表示、ターミナルウィンドウの切り離し、ターミナルのズーム（Ctrl+= / Ctrl+- / Ctrl+0）、14 種類のターミナルテーマ、検索、マクロ、ブロードキャスト入力に対応しています。
- **Linux ターミナルと同じコピー＆ペースト**：選択するとコピー、中クリックで貼り付け、右クリックでメニューを表示（または PuTTY 方式のコピー／貼り付け）でき、Ctrl+Shift+C / Ctrl+Shift+V と Ctrl+Insert / Shift+Insert も使えます。Ctrl+クリックでリンクを開きます。
- **SSH**：ネイティブの OpenSSH セッション、SSH エージェント、`~/.ssh/config` のインポート、ID ファイル、ProxyJump、圧縮、キープアライブ、X11 転送に対応しています。
- **SFTP と FTP/FTPS**：実行前に内容を確認できる転送、フォルダーの転送、比較と同期、インラインでのテキスト編集、転送キューを備えた 2 ペイン型ファイルマネージャーです。SFTP は、OpenSSH の `known_hosts` ですでに信頼済みの鍵をそのまま尊重します。
- **SSH トンネル**：ローカル、リモート、ダイナミック（SOCKS）のポート転送に対応し、実際に動作している場合にのみ準備完了と表示します。
- **リモートデスクトップ**：埋め込みの RDP・VNC タブ、外部の FreeRDP/TigerVNC クライアント、SSH ゲートウェイ経由の RDP/VNC に対応しています。
- **ワークスペース**：名前を付けて保存できるワークスペース、セッションの復元、接続グループ、お気に入り、ワークスペースのバックアップ、ローカルの復元ポイントを利用できます。
- **ターミナルアシスト**：セッションごとの OS 検出、インラインのコマンド候補（Ctrl+Space）、「もしかして」による修正候補、危険なコマンドを実行する前の確認機能を備えており、それぞれ個別に無効にできます。パスワード入力プロンプトで入力した内容は、表示・候補表示・保存のいずれも行われません。
- **生産性**：セッションをまたいだ履歴検索、複数セッションでの同一コマンド実行と出力の集約、セッションの再生、ホストのリアルタイム統計、ネットワークツールを利用できます。
- **オプションの AI ヘルプ**：既定では無効です。ご自身の OpenAI 互換エンドポイント（例：llama.cpp や Ollama）を使用します。回答は挿入されるだけで、実行されることはありません。
- **日本語インターフェース**：インターフェースは 9 言語に対応しており、ステータスバーから切り替えられます。

## クイックインストール

```bash
# AppImage（ポータブル）
chmod +x Aux-Command-0.4.0-x86_64.AppImage
./Aux-Command-0.4.0-x86_64.AppImage

# Debian / Ubuntu
sudo apt install ./Aux-Command-0.4.0-amd64.deb
aux-command

# Fedora / RHEL / Rocky / AlmaLinux
sudo dnf install ./Aux-Command-0.4.0-x86_64.rpm
aux-command

# openSUSE
sudo zypper install ./Aux-Command-0.4.0-x86_64.rpm
aux-command
```

Mosh、RDP（FreeRDP）、VNC（TigerVNC）は、ディストリビューション標準のクライアントを使用します。これらは `./scripts/install-runtime-tools.sh` でインストールできます。詳しくは [INSTALL.md](INSTALL.md) をご覧ください。

## セキュリティ

Aux Command は、目に見えない利便性よりも明示的な信頼境界を優先します。Electron のレンダラーは `contextIsolation` を有効にしたサンドボックス内で動作し、Chromium の権限要求は既定で拒否され、外部へのナビゲーションとポップアップはブロックされます。プロセスはシェルを介さず、引数配列を使って直接起動されます。SSH ホスト鍵と RDP サーバー証明書は初回使用時に確認を求め、変更された場合は警告します。RDP は確認済みの証明書に固定されます。貼り付けたテキストからは制御文字が除去され、複数行の貼り付けやブロードキャストでの貼り付けは事前に確認を求めます。パスワードは暗号化されたデスクトップストレージが利用できる場合にのみ保存され、エクスポートに機密情報が含まれることはありません。

脆弱性は、[SECURITY.md](SECURITY.md) に記載の方法で非公開にてご報告ください。
